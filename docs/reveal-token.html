LyriCue Dropbox Token Setup

A one-time tool for pulling a long-lived Dropbox token out so a backend service can use it — not part of the normal LyriCue tools, not linked from anywhere else on the site.

Important: the Lyric Editor and Setlist Builder share this same browser's Dropbox connection. Connecting here to a different account (e.g. the shared community library account) switches which account those tools are ALSO connected to, on this browser, until you disconnect or reconnect your own account. Copy the token, then disconnect right away if you're about to go back to using the editor for your own songs.
