LyriCue Lyric Editor

A PC-based tool for building song files for LyriCue: paste in a song from the web (a whole copied page, cleaned up automatically) or your own lyrics as you're writing them, and either way get a plain text or ChordPro file you can download or save straight to your LyriCue Dropbox folder.

  1. Paste the copied page below, or type/paste your own lyrics directly.
  2. Click "Clean Up" if you pasted a whole webpage — it strips out navigation, ads, and other page clutter. If it's your own lyrics with nothing to clean, click "Use As Typed" instead to skip straight to saving.
  3. Either way, review the result before saving — cleanup is a helper, not magic.
  4. Fill in the title (and artist, if you have it), then download the file or save it straight to Dropbox.

Editing an existing song instead? Open it from Dropbox and your changes will save back to that same file.

    "Clean Up" strips out navigation, ads, and other page clutter — use it for something copied from a website. "Use As Typed" skips that and takes it exactly as it is — use it for your own lyrics.
